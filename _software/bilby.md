`bilby` is a general-purpose Bayesian inference package that is widely used in gravitational-wave data analysis. I am a lead developer for `bilby` and the related package, `bilby_pipe`.

## Key Features

- General-purpose Bayesian inference
- Extensive sampler support
- Gravitational-wave specific functionality
- Likelihood and prior framework
- Pipeline integration with `bilby_pipe`

## My Contributions

As a lead developer, I have contributed to:
- Core sampling algorithms
- Interface design and architecture
- Gravitational-wave specific features
- Integration with external samplers
- Documentation and testing

- [bilby-pipe](../bilby-pipe/): Automating bilby analyses
