PyCBC is a software package used to explore astrophysical sources of gravitational waves. It contains algorithms to analyze gravitational-wave data from the LIGO, Virgo, and KAGRA detectors, detect coalescing compact binaries, and measure the astrophysical parameters of detected sources.

## My Contributions

I have contributed to `pycbc`, predominantly the `inference` submodule and whilst working on premerger inference for LISA.


- Inference submodule development
- Premerger inference capabilities for LISA
- Bug fixes and performance improvements
